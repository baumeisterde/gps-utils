# gps-utils

Touren planen (Auto, Motorrad, Fahrrad, zu Fuß) mit Karte, Routing, Höhenprofil, Offline-Karten, GPS-Info und Track-Aufzeichnung.

**Hinweis:** Diese App wurde mithilfe von KI erstellt (Claude von Anthropic). Routen, Höhen und Standortangaben ohne Gewähr – vor einer Tour selbst prüfen.
